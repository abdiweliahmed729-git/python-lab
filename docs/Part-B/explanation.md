# Part B – Git and .gitignore

The `.gitignore` file tells Git which files and folders should not be tracked or uploaded to the repository. The `__pycache__/` pattern prevents Python cache folders from being tracked, while the `*.pyc` pattern prevents Python compiled files from being tracked. These files are automatically generated and are not necessary for the source code.

The commit history shows how the project has developed over time. It records commits, commit messages, and the changes made to the project. This helps developers track progress and understand the development history of the project.
