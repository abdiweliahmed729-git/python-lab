Part C – Python Modules and Testing

Python's import system allows code from one Python file to be used in another file. In this project, `main.py` imports functions from `utils.py`. This allows reusable functions to be kept separately from the main program logic and makes the code easier to organize and maintain.

The program was tested using three different inputs: 4, 7, and 0. The program successfully calculated the square, determined whether each number was even, and performed the Celsius to Fahrenheit conversion.
