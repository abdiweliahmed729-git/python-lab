# Part A – Project Structure

The commands used in this section were used to create folders and files and display the project structure. The `mkdir` command creates directories, the `touch` command creates files, and the `find` command displays files and folders recursively.

Separating code into `src`, `tests`, and `docs` is good practice because it keeps the project organized. The `src` folder contains source code, the `tests` folder contains testing files, and the `docs` folder contains documentation. This makes the project easier to understand, maintain, test, and expand.
